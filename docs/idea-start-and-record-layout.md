# 想法开始工作、补充讨论与实验要点

2026-10-09：独立想法点击“开始参与”后输入名称，创建普通项目；项目内想法创建原项目下的实验。创建者主导新工作，原想法作者与正文保留。来源保存想法 ID、名称、作者、版本与内容快照。普通项目更新保留来源；同一想法可创建多条路线，断线重试复用请求键，不重复创建。

想法正文下方显示“补充与讨论”，成员可评论或补充。补充使用 entity_comment 的 kind:extension；不覆盖原文，保留署名与时间，通知想法主导者。

实验使用 report.done / failed / reusable / pending / other 五类分条记录，一行一个分类；“其他”允许自由备注。主动换行成为新圆点条目，自然折行保留在同一条。旧记录缺少 other 时兼容显示为空。旧 summary 与 change_summary 仍保留，可展开查看。明确标记的旧正文可在前端分组展示，未标记内容不强行推断。实验分支不继承旧结论，可提交 report 合并；共同参与成员可更新进展与报告，主导者决定采纳成果。
