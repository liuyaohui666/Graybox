# Graybox 本地个人版 v1 设计

## 产品目标

Graybox v1 是只供本人使用的 Windows 桌面软件。它管理项目、想法、实验和长期学习内容，所有数据离线保存在 `D:\\Graybox`，可通过 `.graybox` 文件完整迁移到另一台设备。

## 功能边界

### 工作内容

- 项目：名称、说明、优先级、状态、标签、GitHub 地址、附件和历史。
- 想法：独立想法或关联项目的想法，支持标签、评论、来源和开始参与。
- 实验：进度、优先级、结果、来源路线、分支和五类报告。
- 学习：学习方向、分支、知识点；知识点支持状态、笔记、标签和复习日期。
- 附件：图片、短视频、静态网页和链接，详情页可预览，管理区放在末尾。

### 数据能力

- SQLite 数据库、附件目录、头像目录、历史活动全部位于 `D:\\Graybox`。
- 导出完整 `.graybox` 迁移包，含清单、哈希、数据库、附件和头像。
- 导入前校验，支持完整替换和按 UUID 合并；冲突不静默覆盖。
- 首次启动自动创建目录；断网仍可使用。

### Codex

- 本机 Skill 通过 loopback API 或本地桥接读写。
- “写入 Graybox”“补写之前进展”读取已有记录并按稳定请求键写入。
- 支持导出、导入和同步状态读取，不需要登录、配对或云端配置。

## 不属于 v1

- 团队账号、邀请码、成员管理、赞同、消息、云端同步。
- 云端服务器运行时依赖。
- 课程平台、积分、打卡和自动生成学习内容。

## 验收

1. 双击桌面快捷方式后直接进入工作台，不显示登录页。
2. 断网时可以创建、编辑、搜索项目、想法、实验和学习知识点。
3. 所有数据文件都位于 `D:\\Graybox`。
4. 关闭并重新打开软件后，新增内容仍存在。
5. 导出的 `.graybox` 在另一台设备导入后，数据、附件、头像和关系一致。
6. 损坏包或 UUID 冲突不会破坏当前数据。
7. 本机 Codex Skill 能读回和写入本地记录。
