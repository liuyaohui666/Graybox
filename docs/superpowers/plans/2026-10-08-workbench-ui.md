# Graybox 0.3.1 工作台界面

用户选定简洁浅色工作台。沿用 React、原生控件与现有 CSS，不新增依赖。

三位熟悉彼此的成员在此录入想法、安排优先级、推进项目、交流和复盘。界面应安静、清楚、便于连续操作。领域元素：想法、待做、主导项目、标签、复盘、讨论、成员头像。

视觉系统：白色内容、浅灰导航、石墨文字、灰色分隔线、低饱和青绿色强调；4px 间距基准。标题 22px、栏目 15px、正文 13–14px，使用已有中文系统字体。以分隔线与层级组织信息，避免均分大卡片、英文装饰标题与宣传句。识别特征为成员头像及下方姓名、带进度和优先级的紧凑项目行。

首页以待推进项目和近期经验为主体。所有项目、成员主页复用项目行。详情先阅读说明与状态，owner 按需展开编辑；草稿在收起后保留。保持赞同、评论、消息、标签跳转以及未知写入结果的全部锁定与重试约束。

验证：类型检查、现有展示/导航/写入安全测试、实际浏览器宽屏与 390px 页面、成员主页、项目编辑展开与草稿保留、标签筛选、头像菜单、消息。复用已验证发布脚本生成 Windows 与云端包，按现有独立 Graybox 更新流程部署，不改数据库模型或其他服务器服务。
