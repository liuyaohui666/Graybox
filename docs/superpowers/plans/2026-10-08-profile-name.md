# Graybox 0.3.2 昵称修改

入口：左下角头像 → 个人资料 → 昵称 → 保存昵称。复用现有账号和头像资料刷新，不更改登录用户名、密码、角色、头像或项目归属。

服务端只接受当前有效 human 的昵称，不接受目标用户或角色字段；昵称去除首尾空白，限制 1–100 字符并拒绝控制字符。006 migration 提供窄范围的凭据派生 SQL 函数，runtime 仍不能直接 UPDATE 用户姓名。新装和升级均包含该迁移。

侧栏、成员列表、成员主页、项目和评论署名使用已刷新的人物目录。云端会话栏同步昵称。个人资料窗口保留提交值，在结果未确认时禁用修改和离开，允许重试同一值；弹窗内可读取服务器昵称并显式确认结束重试。

验证：新增接口测试先观察到 404 失败，然后通过；完整套件 213 项通过；最后接口、展示、传输专项 27 项通过，包含云端改名后以原用户名重新登录；原生测试 8 项通过。实际浏览器已验证保存即时刷新和重载持久化，断线冻结草稿与读取核对。独立审查指出安装迁移遗漏与弹窗恢复入口不足，均已修复并复审通过。
