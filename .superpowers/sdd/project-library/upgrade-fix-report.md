# Upgrade safety fixes

Scope: ops/cloud/upgrade.py, test_upgrade.py, isolated check_upgrade_guard.mjs only. No production commands or deployments.

Implemented full-operation fixed /var/lib/graybox/upgrade.lock with exclusive nonblocking fcntl flock; second operation rejects before preflight/service mutation. Initial service stop is protected. Recovery independently attempts stop, previous-pointer restore, start, and previous health verification; failures cannot suppress later stages or replace the original exception. Public failure state only names failed stages. CLI hides exception text; private report retains backup evidence and public success omits raw backup output.

Migration SQL comes from copied target/db. Capture and validation run inside the migration transaction before COMMIT. Temporary recursive JSON predicate retains every original object key/value, compares arrays/scalars exactly. Each original row consumes a distinct matching after-row, retaining duplicates without positional identity. Private snapshots use canonical JSON multisets, independent of PostgreSQL row ordering and without silent overwrites. Counts include duplicates.
